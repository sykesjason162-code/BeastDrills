# Character art (optional, not included)

Drop character portrait/splash images here to give a drill card a
character-specific background on the Drills page.

- Filename must be `<character_id>.png`, matching the `character_id`
  values used in `shared_database.json` / the dashboard's Character
  dropdown -- e.g. `jp.png`, `dee_jay.png`, `chun_li.png`.
- Only the drill's own `character_id` (the player, not the dummy) is
  looked up.
- These are RIGHT-ALIGNED renders: the subject sits left of centre so the
  art hugs the right edge of a card. The Profile page's centred versions
  live in `../profile_characters/` and are NOT interchangeable with these
  (Jason, 2026-08-27). Read that folder's README before reusing either.
- Art here IS tracked, contrary to what this file used to say. Jason's
  call, made twice and settled: private repo, non-commercial personal
  tool, Capcom enforcement not a real concern. Noted only so a future
  public release remembers to purge the art from history first.
- Cards look correct with no image present at all -- that's the fallback,
  not an error.
